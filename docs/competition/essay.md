# 让 Agent 的工作看得见

仓库：https://github.com/jinyaxuan/TeamPulse

我们做 TeamPulse，是因为团队里的编码 Agent 越来越多，而它们的工作默认是看不见的。一个 Agent 在改接口，另一个 Agent 在补测试，人在聊天窗口里发需求。三边各自以为自己掌握了进度，直到两个分支改到同一批文件，或者一项需求做完了却说不清验收标准是什么。

看板上的卡片要人来搬，Agent 不会把终端里的进度搬过去。聊天记录能留下结论，但两个人同时改一个文件时，它不会提醒。

TeamPulse 记录 Agent 已经发生的动作。设备用认领码绑定到人，这台机器上的任务、心跳和文件触碰都归到这个账号。面板显示谁正在做什么、在哪个分支、碰过哪些文件，并标出重叠。

需求单独走工作项：录入、澄清、就绪、指派、进行、待验收、通过，也可以打回或取消。验收可以由人、Agent 或双方完成。执行者不能审核自己的工作项，通过时要逐条确认验收标准。

JEV 负责分诊，给出建议优先级、要不要先澄清、适不适合交给 Agent，以及交付风险。项目默认关闭。负责人可以采纳一条当前版本上的建议：调整优先级，或把刚录入的事项转入澄清。Agent 继续执行和上报，验收仍由指定的人完成。
